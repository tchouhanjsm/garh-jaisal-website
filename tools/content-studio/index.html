Content Studio

Use these guided forms to add a tour, write a travel guide or add Gallery photos. On a Mac, double-click tools/content-studio/Start Content Studio.command in your project folder to open this editor and its local PHP preview together. Fields marked * are required. Start with Draft while you review the details; changes stay on this computer until reviewed and approved for the live website.

Experiences

Describe the guest experience, choose a photo and add the steps in the order they happen. A Live record will be included in local tour listings and the trip planner after review; Draft is best while you are still working.

Lowercase words separated by hyphens. Existing routes are never overwritten.

Journal

New blog or travel guide

Write the heading and introduction, then add sections below. A saved article gets its own page and a card in the Blog archive when marked Live. Include trustworthy source links; do not promise rates, schedules or inclusions that have not been confirmed.

JPG, PNG, WebP or AVIF, maximum 15 MB.

Write normally—no Markdown or HTML needed. Use one section for each main topic. In the section text, leave a blank line between paragraphs. Optional key points go one per line.

Responsive image delivery

The Node editor runs on port 4173. If you also serve the PHP website locally, enter its base URL here to open newly created pages.

Live = live in your local working tree only. Review in Git, validate the ZIP, and approve staging before production.

This editor is not a public admin page. It only listens on 127.0.0.1 and is not included in the cPanel runtime package. The one-click launcher starts the local preview and editor together; keep its Terminal window open while working, and close that window to stop both services.
