Actual site render

Page preview

The preview uses the same PHP renderer, shared header/footer and approved stylesheets as the website. Unsaved previews are private to this local tool and automatically expire; they do not enter listings or the sitemap.

Use the address printed by the Content Studio launcher. Only localhost or 127.0.0.1 is accepted; the preview never connects to a production or external host.

Responsive image delivery

Uploaded photos are registered in the existing responsive-image manifest. After uploading a batch, generate checked WebP variants; original photos are retained.

This editor is not a public admin page. It only listens on 127.0.0.1 and is not included in the cPanel runtime package. The one-click launcher starts the local preview and editor together; keep its Terminal window open while working, and close that window to stop both services.
