## Working workflow

1. Use each SVG as a composition reference. Canva may import an SVG as one graphic instead of separately editable objects. Create a Canva design at the listed size and rebuild text, shapes and image regions as separate elements when required.
2. Replace every visible `[BRACKETED PLACEHOLDER]`. Use only approved, correctly licensed original photography; keep natural colour and do not upscale soft imagery.
3. Keep the existing wordmark, approved five-colour palette, serif/sans pairing and 6px geometry. Do not invent a sub-brand logo, new font, price, discount, opening hour, review, award, partner status, inclusion, response-time promise or availability.
4. Verify factual and commercial copy against `docs/OWNER-FACTS.md` and current owner-approved source material. Unknown facts stay out of artwork.
5. Use one clear focal message and one primary action. Only include a CTA when its destination is real and approved. Add platform link stickers separately; never draw a guessed QR or fake link.
6. Export for the target channel, then check contrast, crop, spelling, small-screen legibility and the absence of placeholders. Passing source checks is not visual or commercial approval.
